# 3D 魔塔（MTR / 魔塔3D）Win11 复活版

本仓库是 **3D 魔塔（游戏天堂原版）** 在 Windows 11 上的本地复活档案：游戏通过本机 HTTP 服务 + Flash Player 投影版启动，无需联网、无需原厂服务器。

详细的复活修复说明见同目录 **`修复说明.txt`**（原厂广告横幅地址失效导致卡在启动界面的根因与等长搭桥补丁）。

## 一、直接开玩（最快，推荐）

**不用 clone 仓库**：直接到本仓库的 **发行版（Releases）** 下载开箱即玩整合包即可。

1. 打开 **[发行版 Releases](https://github.com/Barry-Wuu/Mota3D-Win11-Revival/releases)**，下载 `Mota3D-Win11-Revival.zip`
2. 解压到任意目录（建议英文路径）
3. 双击其中一个启动器：
   - `play_original.bat` → **原版**（纯原厂体验）
   - `play_cheat.bat` → **作弊版**（内置加血外挂，战斗内外按 <kbd>空格</kbd> 补满血）

　　运行依赖：**Flash Player 投影版** + **Python**（启动器 `.bat` 已内置路径 fallback）。玩完请关掉名为 `mtr-server` 的窗口，否则端口 8777 会被占用、影响下次启动。

## 三、怎么玩（原版 / 作弊版二选一）

仓库同时提供「原版」和「内置加血外挂的作弊版」两个独立 SWF，分别对应各自的启动器。双击其中一个 `.bat` 即可：

- 想纯原版体验：双击 **`play_original.bat`**（启动 `play_original.swf`）
- 想用加血外挂：双击 **`play_cheat.bat`**（启动 `play_cheat.swf`）

　　启动器会先起一个本机 HTTP 服务（127.0.0.1:8777），再用 Flash Player 投影版打开对应 SWF。

　　注意：必须走 `.bat`，不要用 `file://` 直接双击 SWF——Flash 在 `file://` 下禁止读取同目录资源，会进不去游戏。

## 四、加血外挂（仅作弊版 play_cheat.swf）

作弊版把加血逻辑直接编译进了 SWF（4399 无敌版式，非运行时内存扫描），启动即生效，不需要任何配置文件。

> 本游戏有**血量上限**设定（魔塔系列少见的机制），而且**每场战斗胜利后游戏会自动把血量回满**（见 `BattleManager.end()`）。因此「只在非战斗时补满血」在数学上必然是无效操作——你走出战斗时永远是满血，根本没血可补，按空格永远是「已满血，无需补」。所以外挂改为：**只要当前血量低于上限，按空格就补满**，战斗内、战斗外都生效；战斗中掉血时按空格直接回满，才是最实用的时机。

玩法：当前血量**低于上限**时，按一次**空格键**，把当前血量**补满到上限**（上限本身绝不被修改）。

- 空格键显式触发（游戏未占用该键）；除此之外任何时机都**不会**自动加血；
- 每次按下只生效一次（按住不会连补），松键后可再次触发；已满血时按空格会提示「已满血，无需补」，无任何副作用；
- 按键会在屏幕**左上角弹出一个绿色浮字**实时反馈结果（`HP 已补满 -> N` / `战斗中 HP 已补满 -> N` / `已满血，无需补`），方便确认外挂是否已加载、按键是否被识别；
- 想完全不碰外挂：直接用 `play_original.bat` 玩原版即可，作弊版 SWF 完全不加载。

## 五、文件清单

|---|---|
| `play_original.bat` | 原版启动器（起 HTTP 服务 + 开 Flash Player） |
